# Data Availability Notice

Real resident-level source data have been removed from this repository.

The manuscript analysis used restricted long-term care facility data that cannot be publicly distributed because of privacy and data-use requirements. Do not commit real CSV, XLSX, or other resident-level exports to this folder.

For code demonstrations, use the synthetic files generated under:

```text
SYNTHETIC_DATA/
```

The synthetic files are simulated and contain no real resident or facility records.
